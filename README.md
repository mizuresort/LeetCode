## 具体的な進め方（初期）
**第１段階**<br>
1. 問題を解く　1日１問
2. 答えを見ずに考えて5分経っても分からなかったら答えを見る
3. 答えを見て理解したと思ったら答えを隠してコードを書く
4. 筆が進まずに5分経ったら答えを見る 
5. 1回消して全て書き直す
6. 答えを送信　→ 正解<br>

**第２段階**<br>
1. コードを読みやすく整える
    * 過去に同じ問題を解いている人の答えを読む
    * コードとレビューがあるのでレビューコメントを予測するのも良い
        * →他人のコメントを読むと**問題や解法などから連想している知識**があると気づくので書き出して調べる
2. コードが動いた

**第３段階**
1. 書いていたコードを全て消す
2. 時間を測りながらもう一回書く
3. 書いてアクセプトされたら消してもう一回書く
4. これを10分以内に1回もエラーを出さずに書ける状態になるまで続ける
5. 4を3回続けてできるようになったらひとまずその問題はマル

<br> ここで一度レビュー依頼を出す。
